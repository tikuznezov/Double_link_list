# Double link list user manual

В данном проекте реализован двусвязный список с графической отладкой через GraphViz.
```
- Двусвязный список функционирует в массиве структур, а не в отдельных участках памяти.
- Предусмотрен режим _DEBUG, в котором верификатор генерирует изображения со структурой списка, циклом по свободным элементам и элементам с данными.
```

Проект создан в рамках образовательного семестрового курса МФТИ ФРКТ,
под руководством [Ильи Рудольфовича Дединского](https://ded32.net.ru/).

Проект создан на операционной системе MacOS. На иных платформах возможна некорректная работа.


## Установка и запуск:
0) Для систем отличных от mac os следует самостоятельно скомпилировать файл "dl_list.cpp".
  
1) Скачайте архив с проектом, распакуйте в произвольную директорию.
2) Если у вас не установлен компилятор языка С++ -- g++, установите его.
3) При подключении файла "dl_list.cpp" появится возможность использовать указанные ниже функции.
6) Готово!


## Описание функционала:

### Доступные команды:
-> dl_list.cpp

**Поддерживаемые команды:**
| Function | Description |
| ------------ | ----------- |
| InitList | Создает список заданной длины |
| ListDestructor | Уничтожает список, освобождая всю память |
| VerifyList | Проверка списка в режиме дебага |
| PrintDLList | Вывод содержимого списка в консоль |
| PrintListLikeArray | Печать всего массива со списком |
| | |
| ListAddAfter | По индексу в массиве добавляет элемент после указанного |
| ListAddBefore | По индексу в массиве добавляет элемент до указанного |
| ListAddHead | Добавляет элемент в начало списка |
| ListAddTail | Добавляет элемент в конец списка|
| ListDel | Удаляет указанный элемент из списка |
| ListFinderByIndex | По логическому индексу в списке находит адрес элемента в массиве|


### Реализация графического режима отладки:
- Создается текстовый файл "DL_list.gv" с кодом для GraphViz.
- Функция "CompPng(file_name)" создает png файл с текущим состоянием списка.

## Содержимое списка
- Список состоит из структур с индексом предыдущего элемента, данных ячейки, индексом следующего элемента.
- Тип данных ячейки задается через typedef "тип элемента" list_element_t. Далее необходимо указать спецификатор вывода данного элемента и "Ядовитое" значения (необходимо для отладки).
